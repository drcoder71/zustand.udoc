# zustand.udoc – O‘zbekcha Dokumentatsiya 🇺🇿

![Zustand](./images/bear.jpg)

Zustand — bu React uchun yengil va tez state management kutubxonasi.

📌 Maqsad:

- Zustand’ni o‘zbek tilida o'rganish uchun o'zbek tilida documentatsiya

- Oddiy va tushunarli uslubda

## Kimlar uchun?

- React boshlovchilar
- Middle frontend developerlar
- Redux’dan charchaganlar 😄
